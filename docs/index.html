Small rituals.
Honest progress.

Grace is not a scorekeeper. It gives shape to the return: a morning remembered, a few minutes of stillness, a reflection named without judgment, and an evening that can begin again.

01

Hold the day simply

Before sunrise, before work, before sleep — three gentle anchors that make practice visible without making it performative.

02

Name what moved

Write or dictate a private reflection. Local Gemma recognizes one inner movement, with no cloud upload and no rule-based shortcut.

03

Wash it in wisdom

Grace finds the closest passages from the bundled source library and leaves the evidence beside a brief, compassionate response.

What happens on device

The three supplied books become a packaged vector index before release. On the phone, EmbeddingGemma encodes only your query and searches it locally. Gemma 4 E4B provides the private response on the device GPU.

Made for a
real phone.

Grace downloads its public model artifacts only when you ask. Interrupted transfers resume from safe partial files, check the server byte range, verify the final SHA-256, and never touch your existing practice records.

Safe updates

The package remains com.ravi.grace. Version 0.2.7 is an in-place update: no uninstall, no data clear, no renamed preferences, and no removed model paths.

Simple handoff

Install the signed APK from the public release page. Keep roughly 4.1 GB free for the two local models; Wi-Fi is recommended for the transfer.
